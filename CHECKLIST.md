# Analytics Report — What to include when you download

Tick the items you want to appear in the **Download Analytics PDF** report. You can also choose these in the Dashboard under **Customize report** before clicking Download.

---

## Report sections (tick what you want in the PDF)

### Summary & overview
- [ ] **Summary** — Total students, classes, academic years (big numbers)
- [ ] **School-wide averages** — Opener and Midterm average across the whole school
- [ ] **Report title and date** — “Academic Analytics Report” and “Generated on …”

### Performance
- [ ] **Performance by class** — Table: class name, students, Opener avg, Midterm avg, with/missing opener, with/missing midterm
- [ ] **Academic years & exams** — Table: which years have exams, Opener/Midterm yes or no

### Data completeness (future)
- [ ] **Students missing marks by class** — Count of students with no Opener / no Midterm per class (already in Performance by class; can be a separate summary)
- [ ] **Subjects with no results** — Per exam, which subjects have no data (future)

### Class & enrolment (future)
- [ ] **Class teacher per class** — List class and class teacher name (future)
- [ ] **Student count per class** — Already in Performance by class (future: standalone list)

### Trends (future)
- [ ] **Opener vs Midterm trend** — Per class: improved / declined / same (future)
- [ ] **Top / bottom performing classes** — Ranked by average (future)

### Other (future)
- [ ] **Subject-level averages** — School-wide average per subject (e.g. Mathematics 72, English 68) (future)
- [ ] **CBC grade distribution** — Count of EE / ME / AE / BE across school or per class (future)
- [ ] **Footer** — School name and “For internal use” (always on)

---

## How to use

1. **Tick above** — Change `[ ]` to `[x]` for each section you want in the PDF.
2. **On the Dashboard** — Use the **Customize report** checkboxes (they match this list). Then click **Download Analytics PDF**. Only the sections you leave checked are included.
3. **Default** — If you don’t change anything, the report includes all currently available sections.

---

## Currently available in the app

- Summary (students, classes, academic years)
- School-wide Opener / Midterm averages
- Performance by class (full table)
- Academic years & exams table
- Footer

Items marked *(future)* are not built yet; tick them if you want them added later.
